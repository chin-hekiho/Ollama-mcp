# 👗 时尚搭配师

基于LLM项目的女性穿搭AI应用

## 🎯 项目简介

这是一个专业的AI时尚搭配助手，专注于为女性提供个性化的穿搭建议。应用集成了服装配色、包包搭配、鞋子选择等功能，为用户提供全面的时尚搭配解决方案。

## ✨ 主要功能

### 🎨 配色搭配
- 专业的色彩搭配建议
- 多种风格配色方案
- 场合化配色推荐

### 👗 服装搭配
- 完整的服装搭配方案
- 多种风格和场合适配
- 个性化搭配建议

### 👜 包包搭配
- 包包与服装的完美搭配
- 不同场合的包包选择
- 尺寸和颜色搭配建议

### 👠 鞋子搭配
- 鞋子选择与整体风格协调
- 不同跟高和类型推荐
- 场合化鞋子搭配

### 📱 智能搭配
- AI智能推荐搭配方案
- 个性化风格分析
- 体型和预算适配

### 💬 时尚咨询
- 专业时尚建议和解答
- 个性化穿搭指导
- 时尚问题咨询

### ❤️ 我的收藏
- 保存喜欢的搭配方案
- 个人风格偏好管理
- 搭配历史记录

### 📊 风格分析
- 分析个人风格偏好
- 搭配统计和趋势
- 个性化建议

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动应用

方式一：使用启动脚本
```bash
python run_app.py
```

方式二：直接使用Streamlit
```bash
streamlit run app.py
```

### 3. 访问应用

应用将在浏览器中自动打开，地址：http://localhost:8501

## 🛠️ 技术栈

- **前端框架**: Streamlit
- **AI模型**: 基于LLMs-from-scratch项目的GPT模型
- **数据处理**: Python + Pandas
- **机器学习**: PyTorch

## 📊 数据来源

应用包含丰富的时尚数据：
- **服装搭配**: 多种风格和场合的搭配方案
- **配色方案**: 经典、时尚、简约等多种配色
- **包包数据**: 不同类型和场合的包包推荐
- **鞋子数据**: 各种类型和风格的鞋子搭配
- **风格指南**: 详细的风格分析和建议
- **季节性趋势**: 四季时尚趋势分析

## 🔧 开发说明

### 添加新功能

1. 在 `app.py` 中添加新的功能函数
2. 在侧边栏中添加功能选项
3. 更新 `fashion_data.py` 中的相关数据

### 扩展数据集

1. 在 `fashion_data.py` 中添加新的时尚数据
2. 更新相关的查询函数
3. 测试新功能
