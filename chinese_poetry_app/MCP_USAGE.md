# 古诗词 MCP 工具使用指南

## 📖 概述

古诗词工具已集成到统一 MCP 服务器中,可以直接在 Claude Desktop 中使用,无需任何额外配置或 API Key。

## 🛠️ 可用工具

### 1. `poetry_generate` - 诗词生成

根据主题、风格和长度生成中国古典诗词。

**参数**:
- `theme` (必需): 诗词主题,例如:"春天"、"思乡"、"爱情"、"山水"
- `style` (可选): 诗词风格,选项:"唐诗"、"宋词"、"元曲"、"自由发挥"(默认:"唐诗")
- `length` (可选): 诗词长度(句数),范围:4-20(默认:8)

**示例**:
```
请帮我生成一首关于春天的唐诗
```

Claude 会自动调用 `poetry_generate` 工具,参数:
```json
{
  "theme": "春天",
  "style": "唐诗",
  "length": 8
}
```

### 2. `poetry_explain` - 诗词解释

详细解释一首中国古典诗词的含义、背景、艺术手法和文化内涵。

**参数**:
- `poetry_text` (必需): 要解释的诗词内容(完整文本)

**示例**:
```
请解释这首诗:
床前明月光,疑是地上霜。
举头望明月,低头思故乡。
```

### 3. `poetry_continue` - 诗词接龙

根据给定的诗句接续下一句,保持韵律和意境的连贯性。

**参数**:
- `first_line` (必需): 诗词的上一句

**示例**:
```
请为"床前明月光"接续下一句
```

### 4. `poetry_qa` - 诗词问答

回答关于中国古典诗词的问题,包括诗人生平、诗词流派、创作背景、格律知识等。

**参数**:
- `question` (必需): 关于古诗词的问题

**示例**:
```
李白的代表作有哪些?
什么是格律诗?
唐诗和宋词有什么区别?
```

## 💡 使用技巧

### 1. 自然语言交互

您不需要手动指定工具名称,只需用自然语言描述您的需求:

```
帮我写一首关于秋天的宋词
解释一下《静夜思》
为"春眠不觉晓"接下一句
李白和杜甫的诗风有什么不同?
```

Claude 会自动选择合适的工具并调用。

### 2. 组合使用

您可以在一次对话中使用多个工具:

```
帮我生成一首关于月亮的诗,然后解释一下它的含义
```

### 3. 迭代优化

如果生成的诗词不满意,可以要求修改:

```
这首诗太短了,能写长一点吗?
能换一个更悲伤的风格吗?
```

## 🔧 技术细节

### 工具实现位置

所有古诗词工具都在统一 MCP 服务器中实现:
- 代码位置: `/src/tools/chinese-poetry.ts`
- 服务器入口: `/src/index.js`

### 工具返回格式

所有工具返回的是**提示词**,Claude Desktop 会:
1. 接收工具返回的提示词
2. 使用 Claude 的语言能力处理提示词
3. 生成最终的诗词或解释
4. 返回给用户

这种设计确保了:
- ✅ 高质量的中文输出
- ✅ 符合古诗词格律
- ✅ 专业的文学解释

## ❓ 常见问题

### Q: 需要安装什么吗?

A: 不需要!只要您的 Claude Desktop 配置了统一 MCP 服务器,就可以直接使用。

### Q: 需要 API Key 吗?

A: 不需要!完全通过 Claude Desktop 的 MCP 集成使用。

### Q: 生成的诗词质量如何?

A: 由 Claude 生成,质量很高,符合古诗词格律和意境。

### Q: 可以生成现代诗吗?

A: 这些工具专注于古典诗词(唐诗、宋词、元曲等)。如需现代诗,可以直接向 Claude 提问。

### Q: 如何提高生成质量?

A: 提供更具体的主题和要求,例如:
- ❌ "写一首诗"
- ✅ "写一首描写春天江南景色的七言绝句,要求意境优美,押韵工整"
